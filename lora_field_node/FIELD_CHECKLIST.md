| Що перевіряємо       | Як перевіряємо                                                                    | Критерій успіху                                                                     |
| -------------------- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Холодний старт ×10   | 10 разів повністю вимкнути й увімкнути живлення                                   | Кожного разу `POST mask = 0x00`, немає неочікуваних reboot                          |
| POST основних блоків | Запустити пристрій і перевірити Flash, NVS, OLED, Radio                           | Усі 4 тести `OK`, `POST mask = 0x00`                                                |
| Збереження config    | Виконати `config set txPower 15`, перезавантажити пристрій, виконати `config get` | Після reboot `txPower = 15`                                                         |
| Reset config         | Виконати `config reset`, потім `config get`                                       | Значення повернулися до defaults: `txPower=10`, `sendInterval=1000`, `maxRetries=3` |
| Валідація config     | Виконати, `config set txPower 50`                                      | Значення відхилено, у лог потрапив `WARN`, старе значення не змінилося              |
| LoRa telemetry       | Увімкнути другу TTGO як приймач і перезапустити передавач                         | Приймач отримав POST-пакет правильного формату, наприклад `01 01 00 01 00`          |
